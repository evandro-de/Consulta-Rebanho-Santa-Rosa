Publicar para todos os usuários

Isso é opcional e exige um passo único de configuração. O app roda como arquivo isolado no celular de cada pessoa, então uma atualização feita aqui não chega sozinha aos outros aparelhos — a menos que todo mundo aponte para o mesmo endereço na internet. Funciona assim: 1) gere os arquivos abaixo e hospede-os (ex.: Google Drive + Apps Script — veja o guia que te passei); 2) cole o link do manifest.json no campo abaixo — cada usuário faz isso uma vez; 3) da próxima vez que você atualizar aqui, gere os arquivos de novo e substitua-os no mesmo lugar — o app de todo mundo confere sozinho toda vez que é aberto (com internet) e se atualiza automaticamente.

use {file} onde entra o nome do arquivo — ex.: ?file={file} para Apps Script
